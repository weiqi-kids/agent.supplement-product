**脂質體技術商業化：韓國維生素 C 市場的吸收率競爭**

콜마비앤에이치 本週推出脂質體維生素 C（Liposomal Vitamin C 1000），以磷脂質包覆維生素 C 為技術核心，標榜腸道吸收率提升。脂質體技術在歐美市場（如 LivOn Labs、Quicksilver Scientific）早已商業化，但在韓國保健食品市場中仍屬相對新穎的差異化訴求。本週韓國維生素 C 新品採用此技術，顯示韓國品牌正從傳統高劑量維生素 C（≥1,000 mg 一般劑型）向技術型維生素 C 轉型。對應加拿大、美國市場已出現多款脂質體維生素 C 產品，這一技術路線的跨國擴散軌跡值得持續追蹤，尤其是台灣、日本市場的後續跟進時間點。

本週韓國 주식회사 노바렉스 推出「앙쥬 면역젤리 멀티비타민」（免疫軟糖多維生素），集 11 種功能成分於單一軟糖形態，延續韓國機能食品零食化趨勢。對比前一週（W11）韓國出現「비타 크런치」維他命脆片，連續兩週均有美食化劑型新品登記，顯示韓國市場在機能食品零食化賽道的研發佈局已進入密集期。加拿大與日本市場目前在 LNHPD 和 FNFC 框架下，軟糖劑型產品相對稀少，這是韓國市場的結構性差異，也可能成為跨國品牌進入韓國市場的差異化入口。
