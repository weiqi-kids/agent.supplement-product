# Vitamin B12（維生素 B12）

Vitamin B12（鈷胺素）是人體必需的水溶性維生素，在神經系統功能、紅血球生成與 DNA 合成中扮演關鍵角色。本頁面追蹤全球 Vitamin B12 相關產品市場動態。

## 要解決什麼問題？

根據產品健康聲明分析，Vitamin B12 產品主要訴求：

- **神經系統保護**：維持神經髓鞘完整性、預防神經退化
- **能量代謝**：支持葡萄糖、脂肪與蛋白質的能量轉換
- **認知功能**：改善記憶力、專注力，降低失智風險
- **心血管健康**：與葉酸協同降低同型半胱胺酸，減少心血管風險
- **紅血球生成**：預防惡性貧血，維持正常造血功能
- **免疫調節**：支持免疫細胞的正常運作

## 造成問題的原因

現代飲食與生理因素導致 Vitamin B12 缺乏：

- **動物性食物攝取不足**：B12 主要存在於肉類、乳製品與蛋，素食者風險較高
- **胃酸分泌不足**：老年人胃酸減少，影響從食物中釋放 B12
- **內因子缺乏**：胃壁細胞分泌的內因子是 B12 吸收的必要輔助蛋白
- **藥物影響**：長期服用二甲雙胍（糖尿病藥）、制酸劑會降低 B12 吸收
- **腸道疾病**：克隆氏症、乳糜瀉等影響小腸吸收功能
- **年齡增長**：50 歲以上老年人 B12 吸收能力顯著下降

## 作用機轉

Vitamin B12 的生物活性機制：

1. **甲基化反應**：作為甲硫胺酸合成酶的輔酶，將同型半胱胺酸轉化為甲硫胺酸，參與 DNA 甲基化
2. **神經髓鞘合成**：協助鞘磷脂合成，維持神經髓鞘完整性
3. **能量代謝**：作為甲基丙二醯輔酶 A 變位酶的輔酶，參與奇數鏈脂肪酸代謝
4. **紅血球成熟**：與葉酸協同促進紅血球前驅細胞的 DNA 合成
5. **基因表達調控**：影響 DNA 甲基化模式，調控基因表達

## 發展歷史與現況

**發展歷程**：
- 1920 年代：發現惡性貧血可透過肝臟萃取物治療
- 1948 年：科學家成功分離出 Vitamin B12（鈷胺素）
- 1956 年：Dorothy Hodgkin 解出 B12 晶體結構（獲諾貝爾化學獎）
- 1970 年代：合成型 B12（氰鈷胺）成為主流補充型態
- 1990 年代：活性型甲鈷胺受到關注，神經保護研究增多
- 2000 年代：B12 與同型半胱胺酸、心血管疾病的研究深化
- 2020 年代：高劑量舌下錠與噴霧劑型興起，提升吸收效率

**市場現況**（2026 年 3 月）：
- 美國市場主導，占全球登記產品 76.1%
- 錠劑與膠囊合計占 60.7%，仍為主流劑型
- Nature's Way 以 675 筆產品位居全球品牌龍頭
- 加拿大市場以 Jamieson 等本土品牌為主
- 高劑量（1,000 mcg 以上）產品持續成長，主打快速補充
