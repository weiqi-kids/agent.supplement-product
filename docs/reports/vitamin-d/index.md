# 維生素 D（Vitamin D）

維生素 D 是一種脂溶性維生素，也是人體不可或缺的類荷爾蒙物質。它能由皮膚在日照下自行合成，也可透過食物或補充劑攝取。全球維生素 D 缺乏問題相當普遍，是保健食品市場中最廣泛使用的成分之一。

## 要解決什麼問題？

根據產品健康聲明分析，維生素 D 產品主要訴求：

- **骨骼與肌肉健康**：促進鈣磷吸收、維持骨骼密度、降低骨折風險
- **免疫調節**：支持先天與後天免疫系統功能、減少感染風險
- **代謝調節**：協助血糖調節、支持甲狀腺與胰島素功能
- **心血管健康**：維持血壓正常、支持心肌功能
- **情緒與認知**：與血清素合成相關，支持情緒穩定與腦部功能
- **抗衰老**：影響細胞增殖與分化，與多種慢性疾病風險相關

## 造成問題的原因

現代生活導致維生素 D 缺乏相當普遍：

- 室內工作與生活型態減少日照機會
- 防曬乳廣泛使用阻礙皮膚合成
- 高緯度地區（台灣北部、加拿大、韓國）日照強度不足
- 年長者皮膚合成能力下降
- 深色皮膚者合成效率較低
- 食物中維生素 D 來源有限（主要為深海魚、強化食品）
- 肥胖者脂溶性維生素 D 生物利用率較低

## 作用機轉

維生素 D 的生物活性機制：

1. **鈣磷代謝**：在腸道促進鈣與磷的吸收，維持血鈣濃度
2. **骨骼礦化**：與副甲狀腺素協同調節成骨細胞活性
3. **免疫調節**：與 VDR（維生素 D 受體）結合後，調控免疫細胞分化與細胞激素分泌
4. **基因表達**：作為核受體配體，影響超過 1,000 個基因的轉錄調控
5. **抗發炎作用**：抑制 NF-κB 路徑，降低促發炎細胞激素
6. **神經保護**：支持神經細胞存活、調節神經傳導物質合成

## 發展歷史與現況

**發展歷程**：
- 1920 年代：發現維生素 D 可預防佝僂病
- 1940 年代：開始在牛奶中強化維生素 D
- 1970 年代：確認活性代謝物 1,25(OH)₂D₃ 的核受體機制
- 1990 年代：研究擴展至免疫、癌症、心血管等領域
- 2000 年代：大規模流行病學研究揭示全球缺乏問題
- 2010 年代：D3 取代 D2 成為主流補充形式
- 2020 年代：COVID-19 研究重新引發對維生素 D 免疫功能的關注

**市場現況**（2026 年 3 月）：
- 美國市場主導，占全球 72.7%，達 28,452 筆產品
- 膠囊與錠劑為最主流劑型（合計 63.1%）
- Nature's Way、Douglas Laboratories 為領導品牌
- 加拿大市場規模可觀，達 10,615 筆產品
- 韓國市場起步，49 筆產品多來自代工廠
- 高劑量（2000-5000 IU）維生素 D3 產品持續成長
