# Vitamin B2 選購指南

本指南協助您根據需求選擇適合的 Vitamin B2（核黃素）保健食品。

## 為什麼補充 Vitamin B2？

### 與其他 B 群成分比較

| 成分 | 主要功能 | 缺乏症狀 | 是否為 B2 的輔助成分 |
|------|----------|----------|----------------------|
| **維生素 B2（核黃素）** | 能量代謝、抗氧化、活化其他 B 群 | 口角炎、舌炎、畏光、皮膚炎 | — |
| 維生素 B6（吡哆醇） | 胺基酸代謝、神經傳導 | 神經炎、貧血 | ✅ 需 B2 活化 |
| 葉酸 | DNA 合成、同型半胱胺酸代謝 | 神經管缺陷、貧血 | ✅ MTHFR 酶需 B2 |
| 維生素 B12 | 神經保護、甲基化 | 惡性貧血、神經病變 | 部分協同 |

### 誰適合 / 誰不適合

**✅ 建議考慮補充**：
- 素食者與純素食者（主要來源為乳製品、肝臟，素食飲食易不足）
- 長期疲勞、易口角炎、舌炎者
- 偏頭痛患者（醫師評估後可考慮高劑量方案）
- MTHFR 基因多型性攜帶者（影響葉酸代謝，需充足 B2）
- 孕婦與哺乳婦女（需求量增加）
- 高強度運動者（能量代謝消耗增加）

**⚠️ 需諮詢醫師**：
- 服用三環抗憂鬱劑、某些抗精神病藥者（可能影響 B2 代謝）
- 服用抗瘧疾藥（氯奎寧）者
- 腎臟疾病患者（水溶性維生素代謝需注意）

**❌ 一般無禁忌**（水溶性、過量由尿液排出）：
- 尿液可能變黃色（正常現象，為核黃素天然螢光色）

### 2. 形式選擇

| 形式 | 特點 | 適合族群 |
|------|------|----------|
| **核黃素（Riboflavin）** | 標準形式，需在體內轉化為活性型 | 一般健康補充 |
| **核黃素 5'-磷酸（Riboflavin 5'-Phosphate / FMN）** | 直接活性形式，吸收稍佳 | 消化吸收較弱者、追求高效能者 |

### 3. 劑量建議

| 用途 | 每日建議量 |
|------|----------|
| 一般成人每日需求量 | 1.1–1.3 mg（女性/男性 RDA） |
| 一般保健補充 | 2–25 mg |
| 能量代謝支持 | 25–100 mg |
| 偏頭痛預防（需醫師評估） | 400 mg |

> 注意：水溶性維生素，超出需求量由腎臟排出，一般不易中毒，但偏頭痛高劑量方案需醫師監督。

### 4. 品質指標

- **認證標章**：USP、NSF、ConsumerLab 驗證
- **無填充劑**：Pure Encapsulations 等品牌標榜低過敏原配方
- **素食膠囊**：若有飲食限制，確認膠囊材質（植物纖維膠囊為佳）
- **有機認證**：如 MegaFood、New Chapter 的全食物來源產品

## 常見問題 FAQ

### Q1: 吃了 Vitamin B2 尿液會變黃，正常嗎？
**A:** 完全正常。核黃素為天然黃色螢光物質，超出人體需求的部分由腎臟排出，使尿液呈鮮黃色。這是 B2 吸收利用的指標，並非副作用。

### Q2: 複合 B 群和單方 B2 哪個好？
**A:**
- **一般保健**：選複合 B 群，B 族維生素協同作用效果較佳，且通常包含 B2 充足劑量
- **偏頭痛預防**：需要 400 mg 高劑量，必須選單方 B2 或醫師處方補充

### Q3: 核黃素什麼時候吃最好？
**A:** 建議隨餐服用。核黃素需在小腸特定轉運蛋白協助下吸收，每次吸收量有上限（約 27 mg），高劑量者建議分次服用。光照會破壞核黃素，避免在強光下長時間儲存。

### Q4: 素食者適合哪種 B2 產品？
**A:** 多數 B2 補充劑為合成來源，素食可用。選購時確認：
- 膠囊材質（Hypromellose 植物纖維膠囊）
- 無動物性賦形劑
- 標示「Vegan」或「Vegetarian」認證

### Q5: 偏頭痛補充 B2 真的有效嗎？
**A:** 多項 Meta 分析顯示，每日 400 mg 核黃素可有效減少偏頭痛發作頻率，但效果通常在 3 個月後才明顯。此劑量遠超日常需求量，應在醫師建議下使用，並搭配整體偏頭痛管理計劃。

### Q6: B2 與哪些營養素一起補充效果更好？
**A:**
- **B6**：B2 是 B6 活化的必要輔酶，兩者協同支持神經代謝
- **葉酸**：B2 影響 MTHFR 酶活性，有助於葉酸正常代謝
- **鐵**：B2 協助鐵吸收與紅血球生成，貧血預防常見組合
- **鎂**：偏頭痛預防複方中常見 B2 + 鎂搭配

### Q7: B2 缺乏有哪些症狀？
**A:** 常見缺乏症狀包括：
- 口角炎（嘴角裂痛）、舌炎（舌頭發紅腫痛）
- 脂溢性皮膚炎、皮膚乾裂
- 畏光、眼睛充血
- 持續疲勞感
如有上述症狀，建議先就醫排除其他原因。
