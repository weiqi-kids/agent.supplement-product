# Vitamin B2（核黃素 / Riboflavin）

維生素 B2（核黃素）是水溶性維生素，是人體能量代謝不可或缺的輔酶成分，廣泛應用於複合維生素及單方補充劑。本頁面追蹤全球 Vitamin B2 相關保健食品市場動態。

## 要解決什麼問題？

根據產品健康聲明分析，Vitamin B2 產品主要訴求：

- **能量代謝**：協助三大營養素（碳水化合物、脂肪、蛋白質）轉化為能量
- **抗氧化防護**：作為穀胱甘肽還原酶輔酶，維持細胞抗氧化能力
- **皮膚與黏膜健康**：支持皮膚、嘴唇、口腔黏膜正常功能
- **神經系統保護**：參與脂肪酸代謝，支持神經髓鞘合成
- **偏頭痛預防**：Meta 分析顯示高劑量核黃素有助於減少偏頭痛發作頻率
- **認知功能維持**：支持粒線體功能，與神經退化性疾病研究有關

## 造成問題的原因

現代飲食與生活型態導致 Vitamin B2 攝取不足或需求增加：

- 精緻加工食品大量攝取，天然核黃素含量低
- 素食者、純素食者難以從飲食中獲取足量（肝臟、乳製品為主要來源）
- 大量運動者或長期體力消耗者代謝需求上升
- 老年人腸道吸收功能下降，容易缺乏
- 某些藥物（如三環抗憂鬱劑、某些抗瘧疾藥）會干擾核黃素吸收
- 長期飲酒影響吸收與利用

## 作用機轉

Vitamin B2（核黃素）的生物活性機制：

1. **FMN/FAD 輔酶形成**：核黃素在體內轉化為黃素單核苷酸（FMN）和黃素腺嘌呤二核苷酸（FAD），作為多種酶反應的輔酶
2. **能量代謝核心**：FAD 參與電子傳遞鏈，直接支持 ATP（細胞能量）的合成
3. **抗氧化系統**：作為穀胱甘肽還原酶輔酶，維持穀胱甘肽（GSH）的還原型態
4. **B6 活化**：核黃素是吡哆醛激酶的輔酶，協助維生素 B6 轉化為活性形式
5. **葉酸代謝**：參與亞甲基四氫葉酸還原酶（MTHFR）反應，影響同型半胱胺酸代謝
6. **粒線體功能**：系統評價顯示核黃素對神經系統的保護作用與粒線體功能維護有關

## 發展歷史與現況

**發展歷程**：
- 1920 年代：發現「生長因子」（後稱核黃素），黃色熒光性質被識別
- 1930 年代：確認核黃素為維生素 B2，完成化學合成
- 1940 年代：各國開始在麵粉、穀物中強化添加 B2
- 1990 年代：首批 RCT 研究證實高劑量 B2 對偏頭痛的預防效果
- 2000 年代：活性形式（核黃素 5'-磷酸）產品問世，主打提高生物利用率
- 2010 年代：複合 B 群產品普及，B2 多以複方形式出現
- 2020 年代：個人化精準補充趨勢下，MTHFR 基因多型性與 B2 需求的研究受關注

**市場現況**（2026 年 3 月）：
- 美國市場主導，佔全球登記產品 98.5%
- 膠囊為最主流劑型（42.3%），其次為錠劑（29.7%）
- ProCaps Laboratories、Pure Encapsulations 為領導品牌
- 加拿大市場規模較小，共 90 筆登記
- 粉末劑型佔比達 15.7%，反映 B 群強化食品與飲品需求

## 學術研究

最新文獻分析請參閱 [文獻薈萃報告](literature/)，收錄 PubMed 近期 Vitamin B2 相關研究統計。

- 本月收錄 405 篇文獻
- Level 1 證據（Meta-Analysis/Systematic Review）10 篇
- RCT 4 篇

**主要研究方向**：
- 代謝（100 篇）：能量代謝機制、FAD/FMN 輔酶角色
- 活力（62 篇）：粒線體功能、運動表現
- 免疫調節（51 篇）：抗氧化酶活性、免疫細胞功能
- 心血管（41 篇）：同型半胱胺酸代謝、MTHFR 多型性
- 認知功能（40 篇）：神經退化性疾病、偏頭痛預防

**重要系統評價與 Meta 分析**：
- 偏頭痛預防：Meta 分析確認高劑量 B2（400 mg/日）可有效減少偏頭痛發作頻率
- 粒線體神經保護：系統評價顯示核黃素在神經系統疾病的粒線體調節中具治療潛力
- 能量代謝：系統評價揭示核黃素缺乏與補充對能量代謝的雙向影響

**熱門成分組合**：
- B2 + 鐵（52 篇）：貧血防治、紅血球生成
- B2 + 維生素 A（46 篇）：皮膚與黏膜健康
- B2 + 維生素 B6（44 篇）：神經代謝、同型半胱胺酸控制
- B2 + 葉酸（39 篇）：孕期補充、DNA 合成
